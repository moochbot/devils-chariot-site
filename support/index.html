Getting your flights into the app

Devil's Chariot reads the CSV export Flighty produces. Flighty emails you that file rather than saving it to your iPhone, so there is a step in the middle.

  1. Open Flighty and go to Settings.
  2. Tap Account Data.
  3. Tap Export your Flights.
  4. Enter your email address. Flighty sends the file to it.
  5. Open that email on your iPhone. Tap the .csv attachment, then Share → Save to Files.
  6. Open Devil's Chariot and tap Choose CSV File.

From the Mail attachment you can also tap Share → Copy to Devil's Chariot, which skips the trip through Files.

The picker will not let me select my file

The file must be a .csv. If Mail saved the attachment as .txt, rename it in the Files app and pick it again.

"That does not look like a Flighty export"

The app needs three columns present in the file: Date, From, and To. Any CSV carrying those column names imports, so a spreadsheet you maintain yourself works as long as the headers match. Flighty has renamed columns between versions — if a current export fails this check, send the file and it will be fixed in the next release.

Some rows were skipped

The import banner reports rows it dropped. A row is skipped when it has no date, or when either airport code is missing. Everything else in the file imports.

Importing twice

Safe. Each flight carries a stable identifier, so re-importing updates flights in place instead of duplicating them. Import a newer export whenever you want, and the app fills in what is new.

A flight is missing from the map

The map plots an airport only when it can find coordinates for that IATA code. The app ships coordinates for 5,342 airports. A small or newly opened airport can fall outside that list — the flight still counts in every total, it just draws no line. Send the airport code and it will be added.

My mileage does not match Flighty

The app measures great-circle distance between airports. Airlines and Flighty sometimes use flown distance or a published fare distance, which run slightly longer. Expect totals within a couple of percent of each other rather than an exact match.

Deleting your data

Settings → Delete All Flights empties the app. Deleting the app removes the data with it. Nothing is stored anywhere else, so either one is final — see the privacy policy.

Requirements

iPhone or iPad running iOS 16.4 or later. The app works with no network connection.
